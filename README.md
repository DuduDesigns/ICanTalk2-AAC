# ICanTalk2-AAC

A modern, responsive Augmentative and Alternative Communication (AAC) web application designed to empower non-speaking individuals with fast, expressive, and reliable voice output.

## Features

- **Customizable Communication Grid:** Create, edit, and organize dynamic vocabulary tiles tailored to individual user needs.
- **Natural-Sounding Speech Synthesis:** Integrated multi-language text-to-speech (TTS) support for clear verbal expression.
- **Optimized for Accessibility:** Clean, high-contrast user interface designed for touchscreens and assistive input methods.
- **Cross-Platform:** Built for seamless usage across modern web browsers on tablets, mobile devices, and desktops.

## Tech Stack

- **Frontend:** TypeScript, Vite, React (or modern component architecture)
- **Backend / Server:** Node.js / Express (`server.ts`)
- **Package Management:** [Bun](https://bun.sh/)

## Getting Started

### Prerequisites

Ensure you have [Bun](https://bun.sh/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/DuduDesigns/ICanTalk2-AAC.git](https://github.com/DuduDesigns/ICanTalk2-AAC.git)
   cd ICanTalk2-AAC

```

2. Install dependencies:
```bash
bun install

```


3. Set up your environment variables:
Copy the example configuration file and fill in any required values:
```bash
cp .env.example .env

```



### Running the Application

To start the development server:

```bash
bun run dev

```

To build for production:

```bash
bun run build

```
